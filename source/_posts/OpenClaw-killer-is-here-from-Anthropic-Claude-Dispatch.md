OpenAI had Operator which lets you use AI to perform tasks on the web for you. Anthropic has now released their answer to it — **Claude Dispatch**. It is a feature of the Claude desktop app which lets you route tasks to Claude agents from a conversational, mobile-first interface. Let me break down what it is and what it can do.

## What is Claude Dispatch?

Claude Dispatch is a conversational interface built into the Claude app that lets you give instructions in plain language and have Claude agents actually execute them. The key word here is *execute* — not just respond with how to do something, but actually do it.

You describe what you want, Claude figures out which tools and agents are needed, and gets it done. You are not picking tools manually, Claude routes the task intelligently based on what you asked.

## Key features

**Mobile-first interface**

Most AI tooling is designed for a desktop with a keyboard. Dispatch is built mobile-first so you can fire off tasks from your phone. Quick instructions like queuing up research, checking on a running job, or drafting a reply to an email — these are things you want to do on the go, not only when you are sitting at a desk.

**Task scheduling**

You can schedule tasks to run on a recurring basis. Something like "every weekday morning pull the latest news on this topic and summarise it for me" is a valid instruction. The agent runs on that schedule without you having to trigger it each time. It is not just a cron job either — because Claude is executing it, the task adapts to what it finds rather than breaking when something changes.

**Browser automation**

Dispatch agents can control a browser. You can ask it to fill out a form, navigate a web app, or collect data from a site that does not have an API. Because Claude is reasoning about the page it is looking at, it can handle dynamic content and figure out where the relevant information is without needing you to specify exact selectors.

**File access**

Agents can read and write files on your machine. Tasks like "summarise all my meeting notes from this month" or "find duplicate files in this folder" are just a prompt away. Combined with scheduling this becomes very useful — for example an agent that organises your downloads folder every week.

**Multi-agent routing**

For complex tasks that involve multiple steps, Dispatch can break the work across multiple agents. Research, writing, and follow-up can each be handled by different agents as part of a single pipeline. You describe the end goal and Claude figures out the steps.

## How it differs from regular Claude chat

Regular Claude chat is great for back and forth conversation. Dispatch is different in a few ways:

- Regular chat gives you answers, Dispatch takes actions
- Scheduled tasks keep running after you close the app, regular chat is stateless
- Dispatch has access to your file system, browser, and connected tools
- You do not choose which tools to use, Claude picks the right ones for the task

## Conclusion

Claude Dispatch is Anthropic's direct response to OpenAI Operator and it is a solid one. The mobile-first approach makes it practical for everyday use, scheduling and browser automation cover the most common automation use cases, and the intelligent routing means you do not have to think about which tools or agents to pick. If you are already using Claude, Dispatch is worth trying out.
